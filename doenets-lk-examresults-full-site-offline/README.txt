How to open your downloaded website
===================================

Website: https://www.doenets.lk/examresults

1. Extract the ZIP file first. On Windows, right-click it and choose
   "Extract All". On a Mac, double-click it. If you open the website while
   it is still inside the ZIP, images and styles do not load.
2. Double-click this file to open it in your browser:

     index.html (in the website folder)

If menus or forms do not work
-----------------------------
Most pages work when you double-click them. If menus, forms, search or
animations do not respond, your download is not broken: browsers limit
JavaScript in files that you open from your computer.

For developers: open the extracted folder with a local web server.

  - VS Code: install the "Live Server" extension, open the extracted folder,
    then click "Go Live".
  - Python: in the extracted folder, run
      python3 -m http.server      (Windows: py -m http.server)
    then open http://localhost:8000/
  - Node.js: in the extracted folder, run
      npx serve
    then open the address it shows and go to the start page above.
